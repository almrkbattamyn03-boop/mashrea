# طريقة التشغيل

## 1) المتطلبات
لازم يكون عندك **Node.js** متثبت على جهازك.
لو مش متثبت، حمّله من هنا: https://nodejs.org (اختار النسخة LTS)

## 2) الملفات المطلوبة كلها في نفس المجلد
تأكد إن كل الملفات دي موجودة مع بعض في نفس الفولدر:
- index.html / index-ar.html ← الصفحة الرئيسية (عرض القرض والحاسبة)
- apply.html / apply-ar.html ← صفحة تقديم طلب القرض
- login.html / login-ar.html ← صفحة تسجيل الدخول
- loading.html / loading-ar.html ← صفحة الانتظار لحد ما الأدمن يقرر
- admin.html ← لوحة تحكم الأدمن (محمية بكلمة مرور)
- banner.jpg ← صورة البانر المستخدمة في الصفحة الرئيسية
- server.js
- db.json  ← ده بديل قاعدة البيانات (بيتخزن فيه المستخدمين وطلبات الدخول)
- package.json
- start.bat (لويندوز) أو start.sh (لماك/لينكس)

في رابط تبديل اللغة (English / العربية) في أعلى كل صفحة، بينقلك بين النسختين.

**رحلة المستخدم الكاملة**: index.html → (تقدم بالطلب الآن) → apply.html → (متابعة الطلب) → login.html → loading.html → admin.html (بعد موافقة الأدمن)

## 3) التشغيل
- **ويندوز**: دبل كليك على ملف `start.bat`
- **ماك / لينكس**: افتح Terminal في المجلد ده واكتب:
  ```
  ./start.sh
  ```
  (لو ظهرت مشكلة صلاحيات، اكتب الأول: `chmod +x start.sh`)

أو ممكن تشغّله بالطريقة القياسية (لو حملته من GitHub):
```
npm start
```

## 4) الاستخدام
بعد ما يشتغل السيرفر، هيظهرلك في الطرفية:
```
http://localhost:3000
```
افتح الرابط ده في المتصفح — هتلاقي صفحة تسجيل الدخول.

⚠️ **مهم**: لازم تفتح الصفحة عن طريق الرابط ده (`http://localhost:3000`)، مش عن طريق فتح ملف `login.html` مباشرة، عشان يقدر يتواصل مع السيرفر وملف db.json.

## 5) إزاي البيانات بتتخزن
كل بيانات المستخدمين (الاسم، رقم الجوال، الإيميل، الحالة، اسم المستخدم، كلمة المرور) متخزنة في ملف `db.json`.
تقدر تفتحه بأي محرر نصوص (Notepad مثلاً) وتضيف أو تعدل مستخدمين يدويًا.

## 6) ملاحظة مهمة
السيرفر ده بسيط وللتجربة/العرض بس (بيشتغل على جهازك المحلي). لو محتاج ينشر على الإنترنت
بحيث ناس تانية تستخدمه من أي مكان، ده محتاج استضافة حقيقية (hosting) مش مجرد تشغيله على جهازك.

## 7) تحذير أمان قبل الرفع على GitHub
ملف `db.json` فيه أسماء مستخدمين وكلمات مرور بشكل واضح (بدون تشفير). لو الريبو هيكون **عام (Public)**:
- لازم تشيل أي بيانات حقيقية منه قبل الرفع، أو
- تستخدم بيانات تجريبية وهمية بس (زي الموجودة دلوقتي)، أو
- تخلي الريبو **خاص (Private)**.

لو حابب، أضيف `db.json` لملف `.gitignore` عشان ميترفعش خالص، وبدل منه تعمل ملف `db.example.json` (نسخة فاضية أو ببيانات وهمية) يترفع هو بدل الأصلي.
